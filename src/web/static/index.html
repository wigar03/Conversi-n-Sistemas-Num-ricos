Sistemas Posicionales y Espacios Vectoriales

Cualquier número entero en base $b$ puede representarse como un vector de coordenadas $\vec{v} = (d_n, d_{n-1}, \dots, d_1, d_0)$ proyectado sobre la base canónica polinómica de ponderaciones $\mathcal{B} = \{b^n, b^{n-1}, \dots, b^1, b^0\}$.

N = d_n·b^n + d_{n-1}·b^{n-1} + ... + d_1·b^1 + d_0·b^0

Donde cada coeficiente o escalar $d_i$ pertenece al cuerpo finito $\{0, 1, \dots, b-1\}$.

Algoritmo de la División Euclidiana

Para convertir un número decimal a base $b$, se aplica sucesivamente el Teorema del Resto de Euclides:

D = q · b + r, con 0 ≤ r < b

El cociente $q$ se convierte en el dividendo de la siguiente iteración. Dado que cada residuo $r_i$ es estrictamente menor que la base, los residuos leídos en orden inverso forman los escalares $d_i$.

Equivalencia Canónica en Bases 2, 8 y 16

Las bases 2, 8 y 16 están íntimamente ligadas mediante potencias de 2:

2^1 = 2 (Binario) | 2^3 = 8 (Octal) | 2^4 = 16 (Hexadecimal)

Por tanto, 1 dígito octal equivale a un sub-espacio vectorial de 3 bits, y 1 dígito hexadecimal representa un sub-espacio de 4 bits (nibble), garantizando isomorfismo entre sus representaciones.
